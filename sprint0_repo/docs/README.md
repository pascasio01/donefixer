# Documentación en este repo

El corpus canónico de DONEFIXER (Constitución, RF, RNF, ADR, arquitectura, Doc 70, planes) vive en el paquete documental `donefixer/` y es la única fuente de verdad.

**Este directorio contiene únicamente:** plantillas de ADR y RFC para uso del equipo. Todo ADR aprobado se registra en el **ADI** (`ADI_Architecture_Decision_Index.md` del corpus) — nunca solo en este repo.

Regla (POL-EGM-14): la documentación se actualiza en el mismo PR que el código; la verificación de integridad corre en CI.
